## Core Continuity Commands
- `restart_nu_jin_k`
  - full hard continuity rebuild in a brand-new or damaged thread
- `back to the pick up point`
  - return to the last locked main lane
- `pick up point`
  - mark the current lane as the official re-entry coordinate
- `save point`
  - force a continuity refresh before a risky stop, crash, or thread transfer
