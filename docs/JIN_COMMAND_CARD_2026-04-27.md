- `back to the pick up point`
  - return to the last locked main lane

- `save point`
  - force a continuity refresh before a risky stop, crash, or thread transfer

- `active lane: <thing>`
  - names the one main packet that has priority

  - preserve the thought without changing the lane
- `tag for later: <thing>`
  - save it for the rack, do not execute now
