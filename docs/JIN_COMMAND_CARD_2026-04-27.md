## Core Continuity Commands
- `restart_nu_jin_k`
  - full hard continuity rebuild in a brand-new or damaged thread
- `back to the pick up point`
  - return to the last locked main lane
- `pick up point`
  - mark the current lane as the official re-entry coordinate
- `save point`
  - force a continuity refresh before a risky stop, crash, or thread transfer

## Study / Hardening Commands
- `run Mode E self-study loop`
  - deep study / lineage / journal rehardening
- `run Mode D adaptive rehardening`
  - lighter rehardening when the restore is usable but thin

## Scope-Control Commands
- `active lane: <thing>`
  - names the one main packet that has priority
- `idea: <thing>`
  - preserve the thought without changing the lane
- `tag for later: <thing>`
  - save it for the rack, do not execute now
- `ask-first: <thing>`
  - do not execute without explicit signoff
- `doctrine: <rule>`
  - candidate house / Jin / BRO operating rule

## High-Value Engineering Commands
- `analysis only, no edits`
  - inspect without touching code
- `implement this plan`
  - execute the agreed plan
- `review this`
  - code-review mode: findings first, severity-ordered
- `prove it`
  - give tests, artifacts, and residual risk
- `show me the exact pickup point`
  - restate the saved lane and the next move
- `what changed and why`
  - concise engineering summary
- `what is VERIFIED / INFERRED / UNKNOWN`
  - truth-state breakdown
- `red team this`
  - adversarial review / hardening pass
